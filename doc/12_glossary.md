# 12. Glossary

- **ASN**: Autonomous System Number，自治系統編號
- **ccTLD**: Country Code Top-Level Domain，國碼頂級網域（如 .tw、.jp）
- **CDN**: Content Delivery Network，內容傳遞網路
- **DNS**: Domain Name System，網域名稱系統
- **Dual-stack**: 同時支援 IPv4 與 IPv6 的網路環境，裝置可能依連線類型選用不同 IP 版本
- **GeoIP**: 地理 IP 定位技術，透過 MaxMind MMDB 資料庫查詢
- **IATA**: International Air Transport Association，國際航空運輸協會（其機場代碼用於 rDNS PoP 解析）
- **MMDB**: MaxMind Database，MaxMind 二進位地理資料庫格式
- **MTR**: My Traceroute，結合 ping 與 traceroute 的網路診斷工具，單次執行可取得完整路徑統計
- **Pako**: JavaScript 壓縮庫（deflate/inflate），用於 URL-based 資料分享
- **PoP**: Point of Presence，網路接入點（CDN 節點的實際部署位置）
- **rDNS**: Reverse DNS，反向 DNS 查詢（從 IP 查詢 hostname）
- **Ring Buffer**: 循環緩衝區，一種先進先出的固定大小數據結構
- **SLD**: Second-Level Domain，二級網域（如 google.com 中的 google）
- **SRRT**: Real-time DNS Traffic Analyzer（專案名稱）
- **Subscribe**: WebSocket 雙向通訊中，前端發送的訂閱訊息，用於動態切換後端監控的目標 IP（解決跨裝置、跨 IP 版本監控問題）
